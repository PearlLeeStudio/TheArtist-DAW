# Paired listening samples

Three predetermined fixtures from seed 1380: new pop, new jazz, and A-minor hip-hop completion. Each pair uses the same sketch, tempo, genre playback settings and canonical octave-4 voicing function, then the product MIDI exporter. Final first-ranked chord suggestions are preserved, including slash bass. Canonical voicing differs from the editor's interactive voicing choices.

The filenames identify the planner; these files alone are not a blind test. No audio listening was performed. No listening preference, musical quality score or superiority claim was measured. For a blind comparison, have another person hide/randomize the arm labels before rating coherence, cadence, repetition and overall preference. The minor-key completion begins with the same eight-bar sketch in both arms. No API calls or music regeneration were needed for these exports.
