# Hackathon work log

Meta Global AI Developer Hackathon — building period Oct 27 – Nov 4, 2026 (ET);
project submissions due Nov 4, 9:00 PM ET.

[Watch the hackathon demo](https://youtu.be/wC-dkLfot-c) ·
[Try the live workspace](https://artist-daw.pearlleestudio.co)

The product is an AI arrangement tool: source score or chord sketch → harmonic
revision and form → accompaniment → editable DAW delivery. Chord generation is
one component. The [workflow guide](docs/arrangement-workflow.md) describes the
implemented scope; the event record below preserves each contribution's original
evidence and separates it from the pre-existing research and trained models.

## Reliability evidence for the existing Reharmonize agent

The [paired product-agent evaluation](experiments/reharmonize_agent_eval/extended-summary.md)
adds 220 authored passages, two repeats per provider: **440/440 Muse Spark Open**
and **439/440 Muse Spark 1.3** executions passed, with the same real F1 scorer and
constraints. One API timeout remains in the results; no replacement run or retry
was used. The [protocol and tools](experiments/reharmonize_agent_eval/README.md)
retain frozen inputs, tool traces, usage and limits. This is verification of the
existing feature, with no product code, UX or runtime-setting change; it is
separate from the fixed-pool selector study and the 60 Second-ear reviews.

## Baseline (not hackathon work)

The ongoing [development repository](https://github.com/PearlLeeStudio/TheArtist-DAW)
retains its history. The separate public
[submission repository](https://github.com/PearlLeeStudio/TheArtist-Meta-Hackathon)
contains the event's new source, guides, comparisons and raw results as browsable
files. Existing-file edits and extracted pre-event implementation are supplied as
a patch; the original core is a versioned dependency. The setup reconstructs the
finished app in a separate directory. The three-minute demo opens with the distinction
between the pre-existing core and the work built during the event.

This repository starts from the public release snapshot of
[PearlLeeStudio/TheArtist](https://github.com/PearlLeeStudio/TheArtist)
(git tag `baseline`; the code matches the public commit `f043e53` of 2026-08-25).
Everything up to that tag existed before the hackathon and is **not** claimed as hackathon work:

- React 19 score editor: VexFlow staff, Tone.js + smplr playback, piano/guitar voicings,
  Roman-numeral analysis, MIDI keyboard input, per-genre comping/bass/drum playback.
- FastAPI backend serving the author's 25M-parameter Music Transformer for chord generation
  (weights on Hugging Face under `PearlLeeStudio/*`, CC BY-NC 4.0; never committed here).
- Candidate rerank: R1 Sethares roughness and R2 theory retrieval (corpora are user-supplied, not in this repo),
  rule-based song-form post-processing, voice-leading inversions, local-LLM explanations.
- Rule-based three-track arrangement behind `POST /api/generate/song` and MIDI export.
- Training and analysis pipeline under `ai/` and model-card tooling under `model/`
  (published with arXiv 2605.04998 and 2606.07334).
